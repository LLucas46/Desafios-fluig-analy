# Dados de origem

Os arquivos CSV estão separados pelo conjunto de extração do RM. Preserve os nomes e cabeçalhos ao configurar os metadados no CloudConnect.

| Pasta | Atividades | Conteúdo principal |
|---|---|---|
| `RM_Backoffice_ficticio/` | 1–3 | Contas a pagar, contas a receber, faturamento, devoluções e dimensões de backoffice |
| `RM_RH_ficticio/` | 4–5 | Funcionários, movimentações, folha e dimensões de RH |

Os dados são insumos compartilhados: cada atividade deve apontar para os arquivos necessários sem manter cópias divergentes.
